# DANALLODE HUB

DANALLODE HUB est le portail central multiservices du groupe DANALLODE sur Pi Network.
Il centralise, connecte et développe les entreprises, projets et applications du groupe
dans un point d’accès unique et informatif.

## Utilité
- Centraliser les entités du groupe DANALLODE
- Présenter les projets économiques, sociaux et technologiques
- Informer et connecter la communauté Pi

## Conformité Pi Network
- Application accessible via Pi Browser
- Authentification via Pi Auth
- Aucune fonctionnalité de paiement ou financière
- Application informative et utilitaire

## Statut
Application en phase initiale (Testnet)
